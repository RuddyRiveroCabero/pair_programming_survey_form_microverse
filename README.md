# Microverse Survey Form

A responsive survey form built collaboratively via remote pair programming for the Microverse training program.

## About The Project
This project focused on creating an accessible, validated user feedback form while practicing real-world developer workflows, such as code reviews and branch management in a pair-programming environment.

## Key Learnings
* Building accessible HTML forms with native browser input validations.
* Collaborating with a remote partner using Git workflows (commits, feature branches, and pull requests).
* Applying responsive CSS layouts for mobile and desktop screens.
